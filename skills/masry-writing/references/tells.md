# Tells: phrases that mark Arabic as AI or translated

Each row: the tell, why it's a tell, and what an Egyptian writer does instead.
"Drop" means delete it and start with the next real sentence.

## Openers

| Tell | Why | Instead |
|---|---|---|
| في عالمنا المتسارع / في عالم اليوم | Empty framing, from "In today's fast-paced world" | Drop. Start with the point |
| في ظل التطور التكنولوجي الهائل | Same | Drop |
| في عصر الـ ... | Same | Drop |
| هل سبق لك أن ...؟ | Ad-copy hook translated from "Have you ever" | Ask a real, specific question, or drop |
| دعنا نستكشف / لنغص في | "Let's dive into" | Drop, or `تعالى نشوف` in Egyptian if a transition is needed |

## Calques and filler connectors

| Tell | Why | Instead |
|---|---|---|
| يلعب دوراً مهماً / محورياً في | "plays a key role in" | Say what it does: `هو اللي بيخلي ...` |
| على صعيد ... | "on the level of" | Drop or `في ...` |
| في هذا السياق / في هذا الصدد | Filler | Drop |
| من ناحية أخرى | "on the other hand" by reflex | `بس` / `لكن` only if there's a real contrast |
| تجدر الإشارة إلى أن | "It's worth noting" | Drop; just say it |
| لا شك أن / مما لا شك فيه | Fake certainty | Drop |
| بالإضافة إلى ذلك / علاوة على ذلك | List glue | `وكمان` in Egyptian, or nothing |
| حيث إن / حيث ... | Clause glue | Split into two sentences, or `علشان` |
| يُعد ... من أهم ... | "is considered one of the most" | Say the specific thing that makes it matter |
| قم بـ ... (قم بالضغط) | "Go ahead and click" from UI translations | `اضغط` / `دوس` |
| يمكنك ... | "You can" everywhere | Imperative or `تقدر` in Egyptian, only where needed |

## Inflated vocabulary

| Tell | Instead |
|---|---|
| رحلة (for anything that isn't travel) | Name the process |
| تجربة فريدة / لا مثيل لها / لا تُنسى | A specific fact about the experience |
| الأفضل على الإطلاق | A fact, or nothing |
| حلول مبتكرة / متكاملة | What the thing actually does |
| نسعى جاهدين | Drop |
| شغف | Only if the person said it |

## Closers

| Tell | Instead |
|---|---|
| في الختام / وفي النهاية / ختاماً | Drop. End on the last real point |
| نتمنى لكم تجربة ممتعة | Drop, or a concrete next step (`كلمنا على ...`) |
| لا تتردد في التواصل معنا | `لو عندك سؤال كلمنا على [رقم]` |
| إذا كان لديك أي استفسارات | Same |

## Shape

- Three adjectives in a row, every time.
- Every paragraph the same length.
- Bullet points for things that are one sentence.
- A heading on a 60-word text.
- Emoji closing every line.
- Em dashes (—). Arabic writers rarely use them; models do constantly.

## Register slips inside Egyptian text

| Slip | Fix |
|---|---|
| هذا / هذه | ده / دي |
| لا / لم / لن / ليس | مش / ما...ش |
| سوف / سـ | هـ |
| الذي / التي | اللي |
| ماذا / لماذا / كيف / أين / متى | إيه / ليه / إزاي / فين / إمتى |
| لديك / لدينا | عندك / عندنا |
| فقط | بس |
| أيضاً | كمان / برضه |
| جداً (after every adjective) | أوي, or nothing |
